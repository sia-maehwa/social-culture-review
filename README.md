# 사회문화 연습장

사회·문화 단원별 개념 문제, 오답 노트, 실전 모의고사로 구성된 로컬 실행 웹앱입니다.

## ZIP으로 받아 로컬 실행

1. GitHub 저장소의 **Code → Download ZIP**을 선택합니다.
2. 태블릿에서 ZIP을 압축 해제합니다.
3. 압축 해제한 폴더의 **`index.html`**을 Chrome으로 엽니다.

배포용 `index.html`에는 CSS, JavaScript, 2022~2026학년도 평가원 기출 이미지 300장이 모두 포함되어 있습니다. Termux, Python 서버, 별도 설치가 필요하지 않습니다. `app-source.html`, `css/`, `js/`, `assets/`는 수정과 재생성을 위한 모듈형 원본입니다.

## 필기와 화면 이동

- 현재 문제 화면 전체가 필기 영역입니다. 가운데 별도 필기 상자를 늘리는 방식이 아닙니다.
- 스타일러스(펜)는 획을 그립니다. 손가락은 필기로 저장하지 않고 화면을 드래그·스크롤합니다.
- 펜 색상은 빨강, 파랑, 검정, 초록, 보라, 주황 6가지입니다.
- 지우개, 필기 끄기, 실행 취소, 다시 실행, 문항별 전체 지우기를 지원합니다.
- 필기는 퀴즈의 문제 ID별, 모의고사의 시험·문항별로 브라우저 저장소에 구분해 저장됩니다.
- 브라우저가 스타일러스를 `PointerEvent.pointerType = "pen"`으로 전달해야 펜 필기가 구분됩니다. 일부 정전식 터치펜은 손가락 입력(`touch`)으로 인식될 수 있습니다.

## 원본 수정과 실행본 생성

`js/`, `css/`, `assets/`의 모듈형 원본을 수정합니다. `tools/build-offline.js`가 이를 `index.html` 하나로 묶습니다. GitHub Actions가 `main` 변경 시 실행용 `index.html`을 자동 갱신합니다. ZIP을 다시 받으면 갱신된 실행본을 사용할 수 있습니다.

학습 기록과 필기는 브라우저 로컬 저장소에 보관되며 다른 기기와 자동 동기화되지는 않습니다.
