# 사회문화 연습장

사회·문화 단원별 개념 문제, 오답 노트, 실전 모의고사로 구성된 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 인터넷이 연결되어 있으면 Pretendard 웹 폰트를 사용하고, 폰트를 불러오지 못해도 기본 글꼴로 동작합니다.

## 스타일러스 필기

- 단원별 문제 풀이와 실전 모의고사에서 스타일러스(펜) 입력을 지원합니다.
- 브라우저가 `PointerEvent.pointerType`을 `pen`으로 전달할 때만 필기합니다. 손가락 입력은 필기로 저장하지 않으며, 페이지 스크롤과 객관식 답안 선택에 사용합니다.
- 펜, 지우개, 필기 끄기, 실행 취소, 다시 실행, 문항별 전체 지우기를 제공합니다.
- 단원별 문제 필기는 문제 ID별로, 실전 모의고사 필기는 시험 및 문항별로 브라우저 `localStorage`에 저장됩니다.
- 펜이 손가락과 구분되지 않는 경우 태블릿 OS·브라우저가 해당 스타일러스를 웹에 `pen` 입력으로 전달하는지 확인해야 합니다. 일반 정전식 터치펜은 손가락(`touch`)으로 보고될 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 **공개 저장소**를 만듭니다. GitHub Free에서 Pages를 사용할 경우 공개 저장소가 필요합니다.
2. 이 폴더의 내용 전체를 저장소 최상위에 업로드합니다. `index.html`, `css/`, `js/`, `assets/`가 최상위에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
6. Pages 설정 화면에 표시되는 사이트 주소로 접속합니다.

GitHub Pages는 공개 웹사이트입니다. 공개해도 되는 코드·자료만 올리세요. 이 앱의 학습 기록은 각 기기의 브라우저에 저장되므로, 기기 간 동기화나 계정별 클라우드 저장은 제공하지 않습니다.

## 수정 후 반영

GitHub 저장소의 파일을 수정해 `main` 브랜치에 반영하면 Pages가 자동으로 다시 배포합니다.
