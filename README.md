# 사회문화 연습장

사회·문화 단원별 개념 문제, 오답 노트, 실전 모의고사로 구성된 로컬 실행 웹앱입니다.

## ZIP으로 받아 로컬 실행

1. GitHub 저장소에서 **Code → Download ZIP**을 선택합니다.
2. 태블릿에서 ZIP을 압축 해제합니다.
3. 압축 해제한 폴더의 **`index.html`**을 Chrome으로 엽니다.

배포용 `index.html`에는 CSS, JavaScript, 2022~2026학년도 평가원 기출 이미지 300장이 포함되어 있습니다. Termux, Python 서버, 설치, 인터넷 연결이 필요하지 않습니다. `app-source.html`, `css/`, `js/`, `assets/`는 원본 소스입니다.

## 과목 선택

첫 실행 시 과목 선택 화면이 표시됩니다. 실제 문제·해설 데이터가 준비된 과목만 버튼으로 표시하며, 현재 등록된 과목은 사회·문화입니다. 선택한 과목은 브라우저 저장소에 기억됩니다. 추가 과목은 데이터가 준비된 뒤 선택 목록에 등록합니다.

## 스타일러스 필기와 호버

- 문제 화면 전체가 필기 영역입니다. 별도 필기 상자를 늘리는 방식이 아닙니다.
- 스타일러스가 화면에 닿지 않고 버튼·선택지 위를 지나갈 때 팝업처럼 확대되는 호버 효과를 표시합니다.
- 스타일러스는 필기하고, 손가락은 획으로 저장하지 않고 화면을 드래그·스크롤합니다.
- 펜 색상 6가지, 지우개, 필기 끄기, 실행 취소, 다시 실행, 문항별 전체 지우기를 지원합니다.
- 필기는 퀴즈 문제 ID별, 모의고사 시험·문항별로 브라우저 저장소에 구분해 저장됩니다.
- 브라우저가 스타일러스를 `PointerEvent.pointerType = "pen"`으로 전달해야 호버와 필기가 구분됩니다. 일부 일반 정전식 터치펜은 `touch`로 전달될 수 있습니다.

## 갤러리 이미지 노출 방지

`assets/.nomedia` 파일이 해당 폴더와 하위 폴더의 이미지가 Android 갤러리에 등록되지 않도록 합니다. 이미 미디어 목록에 등록된 파일은 기기에서 갤러리 캐시를 갱신한 뒤 사라질 수 있습니다. `.nomedia`는 파일 관리자에서는 이미지를 숨기거나 암호화하지 않습니다.

## 원본 수정과 실행본 생성

`js/`, `css/`, `assets/`의 모듈형 원본을 수정합니다. `tools/build-offline.js`가 이를 최상위 `index.html` 하나로 묶습니다. GitHub Actions가 `main` 변경 시 실행용 HTML을 자동 갱신합니다. 이후 GitHub ZIP을 다시 받으면 갱신된 실행본을 사용할 수 있습니다.

학습 기록과 필기는 브라우저 로컬 저장소에 보관되며 기기 간 자동 동기화는 제공하지 않습니다.
